## Review regression suite

The external review suite exposed cases where the simulator had used event ID order as a proxy for time: location checks could run before an earlier trip, derived facts could be missed, and location after a later trip used the first movement. A follow-up case showed that resolving every same-key fact producer could manufacture a cycle when a future restock depended on the current checkpoint. Fact reads now resolve only producers whose earliest possible completion is at or before the read time. A truly self-produced requirement still raises a cycle error. Future effects do not count as current facts, and missing current facts remain unknown. The cases are retained in `tests/review-regressions.test.ts`.

Verification after the fix: `npm test` passed all 18 behavior tests, `npm run test:browser` passed all 3 Chromium flows, `npm run typecheck`, `npm run lint` and `npm run build` passed. The browser regression checks two restock IDs (`a-restock` and `z-restock`) against the same checkpoint result, as well as a true self-cycle. The first mobile screenshot captured the lazy-loading placeholder; the browser test now waits for the 3D canvas before capturing it.

No Sanity credentials were present. Live Content Lake reads, Studio login, seed and publication are therefore configuration-blocked and have not been represented as tested. No App SDK app, Workflow or AI runtime was installed. The Director is an authenticated Studio custom tool.

`npm audit fix` without forced major changes could not clear all transitive advisories. Updating compatible `styled-components` and Vitest releases reduced the audit from 18 to 14 findings (11 moderate, 3 high). The remaining high findings are in Sanity CLI transitive packages (`adm-zip`, `js-yaml`, `smol-toml`); npm proposed a breaking Sanity downgrade, which was not applied. Review these upstream dependencies before a public deployment, especially any privileged authoring environment. A clean `npm ci` from the lockfile succeeded after the updates.

## Phase 2: timed trajectories and MomentFrame

Kept the existing repository and history at the verified `6d9f5c8` base. The change remains a single Next.js application. The simulator now returns route itineraries with planned and actual departure, waits, timed connection segments and their visual paths. Distance-based sampling follows each segment at the shared playhead; frame rate does not affect event results. The harbor's direct route is three authored segments totaling 10 minutes, the land route totals 35, and the existing ferry path totals 20 elapsed minutes including its wait for the operating window. Each crossing is checked for availability throughout its duration.

MomentFrame now uses the same authored scene entities and prefabs for the original, current variant and chosen recovery preview at the featured event's fixed time. The photographer, subjects and arrangement use authored composition positions. The variant samples actual availability, so absent flowers do not appear in the missed scene. Preview uses its own patched world and fresh simulation; its event list, inspector, presence label and moment status follow that selected version. A preview stays read-only until Apply rechecks and changes the isolated visitor patch. The bridge closure remains locked, and Reset restores the starting revision. Playback status distinguishes planned, waiting, moving, occurred, missed and indeterminate states.

Screenshot review found and corrected two presentation defects before handoff: replacing the camera object during a version switch could leave a desktop frame blank, so the existing orthographic camera is now positioned through the R3F frame callback; and the recovery legend reused a card class, rendering as a block instead of a line. Review also exposed a preview headline that described the underlying missed variant instead of the selected possible preview; the UI now reads from the active world/result pair. `10-causal-inspector-desktop.png` deliberately captures the independently scrolled causal panel beside the scene.

Verification for this phase: `npm run typecheck`, `npm run lint`, `npm test` (25 tests across 3 files), `npm run test:browser` (3 Chromium flows), and `npm run build` all passed. Browser flows exercised the original photograph, early closure, failed photograph and article claim, MomentFrame versions, both verified recoveries, the intermediate ferry wait, Apply, Reset, mobile reduced motion and the unconfigured Studio message. The journey tests reported no page or console errors. Browser screenshots use the local sample; no live Sanity operation was attempted because this checkout has no Sanity credentials configured.
